# Personal Portfolio Website(Archived Project)

This repository contains the source code for my personal portfolio website built with React.js. It was developed as my first portfolio project to showcase my skills, projects, education, and professional experience as a Software Engineer.

> **Note:** This is my original portfolio built with React.js. I have since developed and deployed a newer portfolio using Next.js with updated features, design, and projects. This repository is kept as part of my learning journey and to demonstrate my progress as a developer.

## Features

- Responsive and modern user interface
- About Me section
- Skills and Technologies
- Projects showcase
- Contact information
- Clean and reusable React components

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Tailwind CSS 

## Purpose

The goal of this project was to build my first personal portfolio website and create a central place where recruiters, employers, and collaborators could learn more about my work and technical skills.

## Status

This project is no longer actively maintained. A newer and improved version has been built and deployed using Next.js.

## Future Improvements

This React version has been archived for reference. Future enhancements are being made in the newer Next.js portfolio.
