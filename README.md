# Personal Portfolio Website

This repository contains the source code for my personal portfolio website built with React.js. It was developed as my first portfolio project to showcase my skills, projects, education, and professional experience as a Software Engineer.

> **Note:** This is my original portfolio built with React.js. I have since developed and deployed a newer portfolio using Next.js with updated features, design, and projects. This repository is kept as part of my learning journey and to demonstrate my progress as a developer.

## Features

- Responsive and modern user interface
- About Me section
- Skills and Technologies
- Projects showcase
- Contact information
- Clean and reusable React components
